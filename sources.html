Data Sources & Attributions

HulaMov combines multiple services to provide movie and television discovery, ratings, artwork, cast information and streaming availability.

MDBList

Used by the HulaMov backend for movie and television metadata, ratings, discovery feeds, catalog information and media enrichment where available.

Visit MDBList →

Streaming Availability API by Movie of the Night

Streaming availability information is provided by Streaming Availability API by Movie of the Night.

HulaMov uses this service for supported provider availability, provider catalog information and provider destination links.

Movie of the Night API →

ReelDB

Used where available for cast/person enrichment and actor profile imagery, subject to applicable provider terms and permissions.

Visit ReelDB →

Firebase / Google Cloud

HulaMov uses Firebase and Google Cloud infrastructure for backend API functionality, configuration, caching, security and service operation.

Apple

Apple StoreKit and App Store services are used to offer, verify, restore and manage HulaMov Pro subscriptions.

Apple controls App Store billing and purchase records.

Netflix, Hulu & Peacock

HulaMov may display genuine provider pages for Netflix, Hulu and Peacock inside an in-app WebKit browser.

Provider accounts, subscriptions, content availability, playback and DRM are controlled by the applicable provider.

HulaMov is not affiliated with or endorsed by Netflix, Hulu or Peacock.

Data-source attribution does not imply endorsement by any third party.
